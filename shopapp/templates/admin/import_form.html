Импорт заказов из CSV

Файл должен содержать колонки:

  • user_id — ID пользователя (обязательно)
  • delivery_address — адрес доставки (обязательно)
  • comment — комментарий (необязательно)
  • products_ids — ID товаров через запятую, например: "1,2,3" (необязательно)

Пример CSV:
